# Отправить перевод с телефона через ChatGPT

theme: tech

Чтобы помочь с переводами, не нужны ни компьютер, ни git, ни команды. Если у вас на телефоне есть ChatGPT, он откроет за вас pull request — предложение добавить ваш файл в репозиторий nxGir. Владелец прочтёт его и, если всё хорошо, добавит на сайт. Вот как это настроить и первая проверка, которая меняет всего одну строку.

## 1. Установите GitHub и войдите

Pull request живёт на GitHub, поэтому там нужна учётная запись. Установите на телефон приложение GitHub (Google Play или App Store, издатель GitHub, Inc.) и откройте его. Нажмите Sign in, а если учётной записи нет, создайте бесплатную и войдите. Позже в приложении можно будет открыть и прочесть свой pull request. Всё это можно сделать и в браузере, на github.com.

## 2. Добавьте плагин GitHub

Откройте меню ChatGPT и нажмите Customize.

![Меню ChatGPT, Customize отмечено](chatgpt-pr-1.webp)

Нажмите Plugins.

![Страница Customize, Plugins отмечено](chatgpt-pr-2.webp)

Найдите «github» и нажмите плюс рядом с плагином GitHub от OpenAI. Войдите в GitHub, когда он попросит, и разрешите доступ к вашим репозиториям.

![Поиск github среди плагинов, плюс отмечен](chatgpt-pr-3.webp)

## 3. Попросите тестовый pull request

Начните новый чат и напишите:

please make a test pull request with my name to the serjhnn/nx-gir project

Укажите имя, под которым вас нужно упомянуть: оно показывается над частями, с которыми вы работали.

## 4. Нажмите Allow

ChatGPT спрашивает разрешения, прежде чем что-то делать на GitHub. Здесь он хочет создать новую ветку — отдельную копию файлов, где ждёт ваше изменение, — так что основная ветка не затрагивается. Прочтите, о чём он просит, и нажмите Allow once (или Always allow, если вы доверяете ему во всех таких шагах).

![ChatGPT просит создать ветку в serjhnn/nx-gir](chatgpt-pr-4.webp)

## 5. Результат

Через мгновение появится карточка: номер pull request, репозиторий, ветка, из которой он идёт, изменённые файлы и кнопка Open pull request, которая открывает его на GitHub. В тесте меняется один файл на две строки, и в основную ветку ничего не вливается.

![Pull request создан](chatgpt-pr-5.webp)

## Теперь с переводом

Когда тест сработал, сделайте то же с настоящей частью. Скажите ChatGPT, какую часть какой книги перевести, и что нужно следовать TRANSLATION_GUIDE.md из репозитория: по одной строке современного армянского на каждую строку грабара, строки глав остаются как есть. Попросите положить файл туда, где лежат другие переводы, в books/ashkharhabar/, добавить новую строку в books/TRANSLATIONS.tsv со статусом machine и открыть pull request. Затем откройте pull request и прочтите результат рядом с грабаром, прежде чем его добавят: черновик — лишь начало, а книгой его делают проверяющие.
