# Թարգմանություն ուղարկել հեռախոսից ChatGPT-ով

theme: tech

Թարգմանություններին օգնելու համար ձեզ պետք չեն ո՛չ համակարգիչ, ո՛չ Git, ո՛չ էլ հրամաններ։ Եթե ձեր հեռախոսում ունեք ChatGPT, այն ձեր փոխարեն կստեղծի pull request՝ առաջարկելով ձեր ֆայլն ավելացնել Նախագրի շտեմարանում։

Շտեմարանի պատասխանատուն կկարդա ձեր առաջարկը և, եթե այն համապատասխանի պահանջներին, կավելացնի կայքում։

Հետևելով ստորև ներկայացված քայլերին՝ կարող եք ստուգել, որ ամեն ինչ ճիշտ է կարգավորված, և կատարել ձեր առաջին փորձը՝ փոխելով ընդամենը մեկ տող։

## 1. Տեղադրեք GitHub-ը և մուտք գործեք

Հեռախոսում տեղադրեք GitHub հավելվածը (Google Play-ից կամ App Store-ից, հրատարակիչը՝ GitHub, Inc.) և բացեք այն։ Սեղմեք Sign in։ Եթե դեռ հաշիվ չունեք, ստեղծեք անվճար հաշիվ և մուտք գործեք։

## 2. Ավելացրեք GitHub հավելումը

Բացեք ChatGPT-ի ընտրացանկը և սեղմեք Customize։

![ChatGPT-ի ընտրացանկը, Customize-ը նշված է](chatgpt-pr-1.webp)

Սեղմեք Plugins։

![Customize էջը, Plugins-ը նշված է](chatgpt-pr-2.webp)

Որոնեք «github» և սեղմեք OpenAI-ի GitHub հավելումի կողքի պլյուսը։ Երբ խնդրի, մուտք գործեք GitHub և թույլատրեք օգտագործել ձեր շտեմարանները։

![github-ի որոնումը հավելումների մեջ, պլյուսը նշված է](chatgpt-pr-3.webp)

## 3. Խնդրեք ստեղծել փորձնական pull request

Սկսեք նոր զրույց ChatGPT-ում և գրեք հետևյալ հրահանգը.

```
please make a test pull request with my name to the serjhnn/nx-gir project
```

Նշեք այն անունը, որով ցանկանում եք ներկայանալ․ այն կերևա ձեր ներդրած աշխատանքների վերևում։

## 4. Սեղմեք Allow

ChatGPT-ն նախքան GitHub-ում որևէ գործողություն կատարելը ձեզանից թույլտվություն է խնդրում։ Այս դեպքում այն ցանկանում է ստեղծել նոր ճյուղ (branch)՝ ֆայլերի առանձին պատճեն, որտեղ կկատարվեն ձեր առաջարկած փոփոխությունները։ Այսպիսով, հիմնական ճյուղը կմնա անփոփոխ։

Ուշադիր կարդացեք, թե ինչ գործողություն է նախատեսում կատարել ChatGPT-ն, և սեղմեք Allow once (կամ Always allow, եթե վստահում եք նրան նմանատիպ բոլոր գործողություններում)։

![ChatGPT-ն խնդրում է ճյուղ ստեղծել serjhnn/nx-gir-ում](chatgpt-pr-4.webp)

## 5. Արդյունքը

Մի պահ հետո կստանաք քարտ՝ pull request-ի համարը, շտեմարանը, ճյուղը, որից այն գալիս է, փոխված ֆայլերը և Open pull request կոճակը, որը բացում է այն GitHub-ում։ Փորձի ժամանակ փոխվում է մեկ ֆայլ՝ երկու տողով, և գլխավոր ճյուղին ոչինչ չի միանում։

![Pull request-ը ստեղծված է](chatgpt-pr-5.webp)

## Հիմա՝ թարգմանությամբ

Երբ փորձը աշխատի, նույնն արեք իսկական մասով։ Ասեք ChatGPT-ին, որ գրքի որ մասը թարգմանի և հետևի շտեմարանի TRANSLATION_GUIDE.md-ին՝ աշխարհաբարի մեկ տող գրաբարի յուրաքանչյուր տողի դիմաց, գլուխների տողերը թողնելով անփոփոխ։ Խնդրեք ֆայլը դնել այնտեղ, որտեղ մյուս թարգմանություններն են՝ books/ashkharhabar/, books/TRANSLATIONS.tsv-ում ավելացնել նոր տող machine կարգավիճակով և բացել pull request։ Հետո բացեք pull request-ը և արդյունքը կարդացեք գրաբարի կողքին՝ նախքան ավելացվելը. սևագիրը միայն սկիզբ է, իսկ գիրք այն դարձնում են ստուգողները։

Թարգմանությունները հրապարակվում են CC BY-SA 4.0 արտոնագրով (տե՛ս CONTRIBUTING.md)։ Ուղարկելով թարգմանություն՝ դուք համաձայնում եք դրան։
