# Եղծ աղանդոց

written: 441–449
kind: վիճաբանական երկ
source: Վիքիպեդիա (անգլ.)
status: machine

Եզնիկ Կողբացու երկը չորս գրքից է․ առաջինը՝ ընդդեմ հեթանոսների, երկրորդը՝ պարսից կրոնի (զրվանականության), երրորդը՝ հույն փիլիսոփաների, չորրորդը՝ Մարկիոնի աղանդի։

Ոսկեդարի գրաբարի լավագույն օրինակներից է։ Առաջին անգամ տպվել է Զմյուռնիայում 1762-ին․ բոլոր հրատարակությունները գալիս են 1280-ի մեկ ձեռագրից։
